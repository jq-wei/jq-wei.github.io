Coding agents as control designers: rendered attempts

53 tasks · for each, the best agent attempt and one attempt per failure mode, re-run on public seeds. Built by scripts/portal.py.

This page accompanies a paper on coding agents as control designers. Each task below asks an agent (Claude Code with Opus 5.5, Fable 5.1 or Sonnet 5.5; one session of at most an hour; no neural networks) to write a feedback controller for a simulated plant, and grades the file on held-out seeds. Every video re-runs the final controller of one session through the task's own evaluator on a public seed; the table under it is the official grade on the held-out seeds. For each task the best attempt is shown and one attempt per failure mode, and for a few solved tasks the weakest passing attempt as well. A few clips come from an earlier sweep with other models under a different harness; their pages say so. The exploration tasks at the end were built after the paper's sweep and are not in its main counts. The tasks, the controllers with their grades and the scripts that build this page are released with the paper.
